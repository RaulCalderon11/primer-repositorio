¿QUÉ ES GIT?

INTRO // v1.0

Git es un sistema de control de versiones distribuido que funciona como un historial avanzado de cambios para cualquier proyecto. Permite registrar modificaciones, saber quién cambió qué y cuándo, volver a versiones anteriores cuando algo falla, y trabajar en equipo sin interferencias. Es el estándar en el desarrollo de software moderno.

CREÉ MI CUENTA EN GITHUB

PROCESO // PASO A PASO
  • Vi un video explicativo sobre Git y GitHub — mucho más claro de lo esperado.
  • Ingresé a github.com y pulsé el botón Sign up visible en la pantalla principal.
  • Registré mi correo, creé una contraseña segura y elegí mi nombre de usuario.
  • Verifiqué la cuenta copiando el código enviado a mi correo.
  • Respondí preguntas de personalización del uso de la plataforma.
  • Seleccioné el plan gratuito — más que suficiente para comenzar.
